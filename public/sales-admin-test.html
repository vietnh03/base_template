Sales Admin API Tester

1. Đăng nhập Admin (Lấy Sanctum Token)

2. Danh sách Đơn hàng (GET /api/admin/sales/orders)

3. Cập nhật trạng thái Đơn hàng (PUT /api/admin/sales/orders/{id}/status)

4. Xem chi tiết Đơn hàng (GET /api/admin/sales/orders/{id})

5. Tạo Đơn hàng mới từ Admin (POST /api/admin/sales/orders)
